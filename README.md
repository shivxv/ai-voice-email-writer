# AI Voice Email Writer

An AI-powered application that converts voice transcripts into professional emails using Gemini AI.

## Features

- User Authentication (JWT)
- AI Email Generation
- Email Translation
- Email History
- Email Sending via Nodemailer
- MongoDB Storage

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Gemini AI
- Nodemailer

## Installation

npm install

## Run

npm start
